# Security

## Supported versions

Security fixes go into the latest minor release. Upgrade to it to get them.

## Reporting a vulnerability

Please report a vulnerability privately, through the repository's [Security tab](https://github.com/sskaye/forgegraph/security/advisories/new), not in a public issue. Say what's affected, how to reproduce it, and what it lets someone do. You'll get a reply there, and the fix is released with an advisory once it's ready.
