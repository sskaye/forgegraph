# Acme graph conventions

- Slides use the acme/slide format; reports use forgegraph_default/compact_format.
- Polarization curves extend acme/polarization-curve: current density in mA/cm² on x, cell voltage on y, one color per cell.
- Write units in parentheses after the quantity: "Cell voltage (V)".
- Name cells as the lab does: "Cell A", "Cell B"; the benchmark is always "Benchmark".
