Specification changes

Every change to the specifications since you approved them at the phase 1 gate, for confirmation at the phase 3 gate. Descriptions aren't listed: they were rewritten during the review rounds and are in the catalog.

Rules

  • Parameters nest in categories and sub-categories to any depth (axis.tick.minor.num). A path is unique across the theme, format and graph type, and no path is the start of another.
  • No parameter name ends in _mult. Every size, width, length and gap is a multiple of figure.base_size, as before, and its description says so (× base size).
  • New type for allowed values: hex colors, a list of one or more hex color codes (series.colors).
  • The ways of naming series are direct (names beside the lines), key (a boxed list) and none, in legend.methods and legend.method; they were interior, legend and none.
  • The data source specification is unchanged since you approved it in phase 2.
