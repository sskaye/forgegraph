# Feature requests and bug reports

If the user asks you to submit a feature request or bug report, file a GitHub issue at https://github.com/sskaye/forgegraph/issues. Write it under the headings of the matching issue form: for a feature request, what you're trying to make, what ForgeGraph does today, an example, and the ForgeGraph version; for a bug report, what happened, what you expected, the GraphSpec or layout, the image, and the ForgeGraph version.

## Issues with a custom pack

If the user asks you to submit a request relating to a custom pack (one not built into ForgeGraph), submit the issue at the address in the pack's pack.yaml, under `issues`.
